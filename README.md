# reel-engine-claude (backup)

Backup of Bilel Bouzid's **claude-shorts** video-editing tool work (the tool itself is the open-source `AgriciDaniel/claude-shorts`; these branches hold his custom styles and compositions).

## Branches

- `feat/news-style` — FR/DE news reels style: YouTube extracts, Anton karaoke captions (yellow active word), teaser+hook in a single render, badge, CTA, face-tracked speaker centering, embedded 1.2s cover/title card.
- `feat/dollarmindlab-style` — Say It Save It MoneyCards composition: DollarMindLab reference style (white top transformation bar, numbered black-box points, white YES/NO bottom CTA), JSON-driven, Ken Burns motion backgrounds, extracted trending music.
- `feat/arabic-kinetic` — Arabic kinetic-typography motion graphics (red/black/gold, RTL text, Cairo Black), JSON-driven scenes with parameterized text lines.
- `feat/script-cards` — ScriptCards composition: kinetic text cards for Say It Save It money-saving scripts (first reusable Save It composition).

Each branch is a full snapshot; see `BACKUP-NOTES.md` in each branch for the source commit and the binary files skipped during backup.
